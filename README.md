## 🚀 Тез баштоо

```bash
# Зависимостиларды орнотуу
npm install

# Development режиминде иштетүү
npm run dev

# Production үчүн түзүү
npm run build
npm start
```

Сайт `http://localhost:3000` дарегинде ачылат
